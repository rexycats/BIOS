BIOS-oefenomgeving

Oefen veilig in een gesimuleerde UEFI-BIOS. Niets kan stuk. Los daarna storingen op, en voer de stappen uit op je eigen virtuele machine.

1. Oefenen 2. Storingsmodus 3. Nu op je VM

In de pc-kast

Hardware wijzig je alleen als de pc uit staat. De USB-stick mag er altijd in en uit.

Fictief moederbord "LAB H310M-A" (Intel H310-chipset). Indeling, menu's, meldingen en sneltoetsen zijn gebaseerd op de ASUS UEFI-BIOS van de klas-pc's (ASUS H310M-A R2.0). Klik op het scherm om het toetsenbord te gebruiken: pijltjes, Enter, Esc, DEL, F1–F12.

Dezelfde stappen op je virtuele machine

Een VM heeft een eigen, eenvoudige "virtuele BIOS". Die ziet er anders uit dan de BIOS van de klas-pc, maar de begrippen blijven dezelfde: POST, bootvolgorde, Secure Boot, paswoorden en standaardwaarden. Kies hieronder het programma dat je gebruikt.

VMware Workstation

Klassieke Phoenix-BIOS (legacy) of UEFI

  1. Zet de VM uit. Kies VM › Power › Power On to Firmware. Je komt meteen in de BIOS, zonder te moeten timen.
  2. Of: start de VM, klik in het venster en druk snel op F2. Te snel? Zet bios.bootDelay = "5000" in het .vmx-bestand (5 seconden wachten).
  3. Legacy BIOS: tabbladen Main, Advanced, Security, Boot, Exit. Bij Security zie je Supervisor- en User Password. Bekijk ze, stel niets in.
  4. Bootvolgorde: tab Boot, item selecteren en verplaatsen met + / -.
  5. Secure Boot: VM uitzetten › Settings › Options › Advanced › Firmware type UEFI › vink Enable secure boot aan.
  6. Standaardwaarden: tab Exit › Load Setup Defaults, daarna F10 om op te slaan.

VirtualBox

Legacy BIOS of EFI (OVMF)

  1. Legacy BIOS heeft geen instelscherm. Je kunt bij het opstarten alleen F12 drukken voor het bootmenu.
  2. Zet de VM uit › Instellingen › Systeem › Moederbord › vink EFI inschakelen aan.
  3. Start de VM en druk meteen herhaaldelijk op F2 of Esc. Je komt in het EFI-instelscherm met Device Manager, Boot Manager, Boot Maintenance Manager.
  4. Bootvolgorde: via Boot Maintenance Manager › Boot Options › Change Boot Order, of in de VM-instellingen bij Opstartvolgorde.
  5. Secure Boot (VirtualBox 7): Instellingen › Systeem › Moederbord › Secure Boot inschakelen (EFI moet aan staan).
  6. Zet EFI na de oefening terug zoals het was. Een geïnstalleerde Windows-VM start niet meer als je de firmware-modus verandert.

Hyper-V

Generatie 2 = UEFI, generatie 1 = BIOS

  1. Hyper-V heeft geen BIOS-scherm in de VM. Alles staat in Instellingen van de VM (VM eerst uitzetten).
  2. Generatie 2: Security › Enable Secure Boot, met de template Microsoft Windows.
  3. Bootvolgorde: Firmware (gen. 2) of BIOS (gen. 1), verplaatsen met Move Up / Move Down.
  4. TPM: Security › Enable Trusted Platform Module (nodig voor Windows 11).

In Windows (in je VM) controleren

  • Secure Boot-status en BIOS-modus: druk Win+R, typ msinfo32, Enter. Kijk bij Systeemoverzicht naar Status van beveiligd opstarten en BIOS-modus (UEFI of Verouderd). Dat is het antwoord op vraag 19.
  • Alternatief in PowerShell als administrator: Confirm-SecureBootUEFI geeft True of False.
  • BIOS-versie zonder herstarten (opdracht 2): msinfo32 › BIOS-versie/-datum, of PowerShell Get-CimInstance Win32_BIOS, of het programma Speccy › Motherboard › BIOS.
  • Screenshots voor je opdracht: Win+Shift+S (Knipprogramma) werkt ook op het VM-venster terwijl de VM in de BIOS staat.
